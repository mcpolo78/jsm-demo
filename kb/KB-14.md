# PC lent ou qui chauffe

1. Redémarrez complètement le PC (Démarrer > Redémarrer, pas seulement fermer le capot).
2. Ouvrez le Gestionnaire des tâches (Ctrl + Maj + Échap) et repérez les applications qui consomment le plus.
3. Installez les mises à jour Windows en attente.
4. Posez le portable sur une surface dure pour ne pas boucher les aérations.
Si le problème persiste, le support lance un diagnostic matériel à distance.
