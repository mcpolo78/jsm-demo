# Outlook ne reçoit plus de mails

1. Vérifiez sur le webmail (https://outlook.office.com) : si les mails y arrivent, le problème vient d'Outlook sur le poste.
2. Fermez Outlook, puis relancez-le. Vérifiez en bas de la fenêtre qu'il n'est pas en mode « Hors connexion » (onglet Envoi/réception > Travailler hors connexion).
3. Si le problème persiste : Panneau de configuration > Courrier > Profils > Ajouter un nouveau profil, puis définissez-le par défaut.
4. Redémarrez le poste. Si rien ne change, le support recréera le cache Outlook à distance.
