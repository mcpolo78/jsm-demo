# Réinitialiser son mot de passe Windows

1. Vérifiez que la touche Verr. Maj n'est pas activée et que le clavier est bien en AZERTY.
2. Rendez-vous sur le portail de réinitialisation libre-service https://motdepasse.groupe.local depuis un smartphone ou un autre poste.
3. Validez votre identité avec le code reçu par SMS, puis choisissez un nouveau mot de passe (12 caractères minimum, dont un chiffre et un caractère spécial).
4. Sur votre poste, connectez-vous avec le nouveau mot de passe. Si le PC est hors du réseau, connectez d'abord le VPN depuis l'écran de connexion.
