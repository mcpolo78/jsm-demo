# Une application Office plante à l'ouverture d'un fichier

1. Ouvrez l'application en mode sans échec : maintenez Ctrl en lançant Excel.
2. Essayez d'ouvrir le fichier via Fichier > Ouvrir > flèche du bouton Ouvrir > « Ouvrir et réparer ».
3. Si le fichier est sur OneDrive ou SharePoint, restaurez une version précédente (clic droit > Historique des versions).
4. Si toutes les applications Office plantent : Paramètres > Applications > Microsoft 365 > Modifier > Réparation rapide.
