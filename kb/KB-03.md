# Demander l'accès à un dossier partagé

1. Faites la demande via le portail en précisant le chemin exact du dossier (ex. \\srv-fic\finance) et le niveau d'accès souhaité (lecture ou lecture/écriture).
2. Indiquez le nom de votre manager : sa validation est obligatoire.
3. Une fois l'accès accordé, déconnectez-vous puis reconnectez-vous à votre session pour que les droits soient pris en compte.
Délai habituel : 1 jour ouvré après validation.
