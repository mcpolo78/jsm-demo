# Installer un logiciel

1. Ouvrez l'application « Portail d'entreprise » (Company Portal) sur votre PC.
2. Cherchez le logiciel (ex. Power BI Desktop) et cliquez sur Installer : aucun droit administrateur n'est nécessaire.
3. S'il n'est pas dans le catalogue, faites une demande sur le portail avec le nom du logiciel et le besoin métier. Une validation peut être nécessaire pour les logiciels payants.
