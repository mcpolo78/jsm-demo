# L'imprimante affiche un bourrage ou ne répond plus

1. Éteignez l'imprimante, ouvrez tous les capots et vérifiez qu'aucun morceau de papier ne reste coincé, y compris dans le bac recto-verso.
2. Rallumez-la et attendez la fin de l'initialisation.
3. Sur votre PC, supprimez les travaux bloqués : Paramètres > Imprimantes > Ouvrir la file d'attente > Annuler tous les documents.
4. Si le message persiste sans papier coincé, le capteur est sans doute encrassé : le support envoie un technicien ou contacte le prestataire.
