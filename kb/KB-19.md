# Licence logicielle expirée

1. Déconnectez-vous du logiciel (Aide > Se déconnecter), puis reconnectez-vous avec votre adresse professionnelle.
2. Si le message persiste, la licence n'est peut-être plus attribuée à votre compte : le support vérifie l'affectation dans la console de gestion des licences.
3. Pour un besoin ponctuel de signature, l'outil de signature électronique du groupe est disponible sur l'intranet.
