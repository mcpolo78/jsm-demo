# Installer la signature mail officielle

1. Téléchargez le modèle de signature sur l'intranet, rubrique Communication > Signature.
2. Dans Outlook : Fichier > Options > Courrier > Signatures > Nouveau.
3. Collez le modèle, remplacez nom, fonction et téléphone, puis définissez-la comme signature par défaut pour les nouveaux messages et les réponses.
