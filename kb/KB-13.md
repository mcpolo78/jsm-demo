# Écran externe non détecté sur la station d'accueil

1. Débranchez puis rebranchez le câble USB-C de la station d'accueil, côté PC.
2. Appuyez sur Windows + P et choisissez « Étendre ».
3. Mettez à jour le firmware de la station via l'outil Dell/HP/Lenovo installé sur le poste.
4. Testez avec un autre câble d'écran. Si l'écran reste noir, le support remplace la station.
